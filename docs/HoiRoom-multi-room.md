# HộiRoom — multi-room MVP

Bản code-only; không viết hoặc chạy test mới.

- Cinema, DJ Club, Music Box với sức chứa tùy chỉnh; phòng riêng dùng mã mời bí mật.
- Sân khấu DJ 3D và nhúng YouTube/SoundCloud theo quyền nhúng của nhà cung cấp.
- Music Box: karaoke và mic WebRTC P2P (tối đa 8 người); HTTPS/localhost là bắt buộc; có thể cần TURN khi NAT chặn.
- Bảo toàn skin, trang phục, ghế Cinema, hàng chờ, ví sandbox và chiếu ảnh ưu tiên.

Chạy bằng npm ci && npm run dev. Không dùng tiền thật.
